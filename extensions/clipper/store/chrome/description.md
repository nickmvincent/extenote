# Extenote Web Clipper - Chrome Store Description

## Short Description (132 chars max)
Clip web pages as structured markdown. Search academic APIs, extract metadata, save bookmarks with one click.

## Detailed Description

### Save web pages as structured markdown for your knowledge base

Extenote Web Clipper helps researchers, students, and knowledge workers save web content as clean, structured markdown files.

**Reference Clipping**
• Multi-source search - Query DBLP, Semantic Scholar, OpenAlex, and Crossref simultaneously
• Smart detection - Automatically extracts DOI, arXiv ID from academic URLs
• Auto-select - Picks the most complete metadata source
• Editable fields - Title, authors, venue, year, DOI, and tags
• Tag suggestions - Content-based tag recommendations

**Bookmark Saving**
• Quick save any page with minimal friction
• Platform detection for Twitter/X, Bluesky, Mastodon, GitHub
• Include selected text as quotes
• Extract post content from social platforms

**Keyboard Shortcuts**
• j/k - Navigate sources
• 1-5 - Select source directly
• Ctrl+S - Save
• Esc - Close

**Two Modes**
1. Download Mode: Save markdown files directly
2. API Mode: Connect to Extenote server for vault integration

**Privacy-Focused**
• No tracking or analytics
• Data stays local
• Only queries public academic APIs
